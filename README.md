# Radiant 34 Brand

Radiant 34 is a Bible-inspired clothing label built around Psalm 34:5:

> Those who look to Him are radiant; their faces are never covered with shame.

The brand exists to create premium Christian art and everyday clothing that carries faith, identity, hope, and bold visual design without feeling cheap, generic, or overly churchy.

## Core Idea

Radiant 34 should feel like a serious lifestyle label, not just a merchandise project.

The visual language is:

- radiant, not dark or gloomy
- premium, clean, and investment-ready
- Bible-inspired, but wearable every day
- warm light, sun rays, cream, gold, black, off-white
- simple enough for Shopify, strong enough for brand storytelling

## Product Categories

Initial product range:

- T-shirts
- Tank tops
- Hoodies
- Key chains
- Bracelets
- Water bottles
- Backpacks

## Build Goal

Create a clean website and Shopify-ready brand system that can be used for:

1. Product presentation
2. Investor/pitch conversations
3. Launch preparation
4. Future Shopify integration
5. Product image generation and mockup organisation

## Technical Direction

Recommended stack:

- React + TypeScript
- Vite
- Tailwind CSS
- Shopify integration later
- GitHub as the source of truth
- Vercel or Netlify for deployment

## First Milestone

Build a one-page brand website with:

- Hero section
- Logo/brand identity presentation
- Psalm 34:5 story section
- Product showcase
- Brand values
- Investor-ready pitch section
- Email/signup CTA

## Brand Rule

The logo does not need to appear on every product. Some products should carry scripture, art, symbols, sun-ray graphics, or minimal radiant marks instead.
