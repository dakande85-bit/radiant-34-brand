# Radiant 34 Shopify Plan

## Goal

Prepare Radiant 34 so the website, product data, and brand story can move into Shopify cleanly when the store is ready.

## Recommended Shopify Setup

Use Shopify for:

- Product catalogue
- Payments
- Inventory
- Discounts
- Email capture
- Product collections
- Checkout

Use the custom website for:

- Brand storytelling
- Investor presentation
- Campaign pages
- Lookbook/editorial visuals
- Future custom landing pages

## Initial Collections

1. Apparel
2. Accessories
3. Everyday Carry
4. Launch Capsule
5. Psalm 34:5 Collection

## Product Data Fields

Each product should include:

- title
- handle
- category
- description
- spiritual meaning
- colours
- sizes
- price estimate
- product images
- mockup status
- supplier status
- launch priority

## Website Integration Options

Option A: Shopify-only

- Fastest to sell
- Less custom design freedom
- Good for MVP

Option B: Custom website plus Shopify buy buttons

- Best for brand presentation
- Good for investors
- Easier to make premium

Option C: Full custom storefront using Shopify backend

- Best long term
- More development work
- Use after brand proves demand

## Recommended Path

Start with Option B:

Custom Radiant 34 landing site first, then connect Shopify products and checkout when ready.
