# Radiant 34 Design Reference Library

This library records the approved visual references uploaded by Daré for future product art, mockups, campaigns and AI image generation.

## How to use this file

- Treat the source artwork as **inspiration and approved direction**, not as permission to redraw it inaccurately.
- Preserve the exact message and scripture reference unless the reference is flagged below.
- For product mockups, use the **actual Shopify/Gelato product shape, colour, seams, proportions and print area**.
- Generate separate website assets, never collages:
  - `primary` — clean product card image
  - `hover` — alternate angle or back artwork
  - `lifestyle` — person using/wearing the exact product
  - `detail` — close-up of print and material
  - `alternate` — back, side, interior or second context
- Default website ratio: 4:5, full product visible, neutral cream background, `object-fit: contain`.
- Never invent a supplier product, garment cut or print placement.

## Radiant 34 visual system

- Core palette: warm cream, ivory, black, charcoal and restrained gold.
- Premium, minimal, scripture-literate, editorial.
- Prefer one dominant phrase, one symbol and one scripture reference.
- Remove unnecessary clip-art, excessive stars, gradients and decorative clutter when adapting references into the Radiant 34 system.
- Recommended print hierarchy:
  - small left-chest mark or short phrase
  - larger back message/artwork
  - scripture reference in small uppercase type
- Do not expose Gelato, Printful or blank-garment branding.

## Future generation reference language

Use the design IDs in prompts and tasks. Examples:

- `Generate a Radiant 34 cropped sweatshirt using R34-D013, cream garment, small front floral mark, 4:5 product card.`
- `Create a black oversized tee using R34-D005, corrected Revelation 19:16 reference, small chest cross, large back typography.`
- `Create five standalone mockups for R34-D008 on the exact Shopify tee: primary, hover, lifestyle, detail and back.`

## Repository asset destination

When the actual PNG source files are committed, place them in:

`public/design-library/source/`

Use safe filenames matching the design IDs, for example:

- `r34-d013-fearfully-wonderfully-minimal.png`
- `r34-d014-fearfully-wonderfully-flower.png`

Generated product mockups belong in:

`public/images/products/<shopify-handle>/`

Do not use source artwork files directly as product card images. Product cards require realistic mockups of the actual product.
